# Code of conduct

Purgeon's issue tracker and pull requests are a shared workspace. Keep
them usable for everyone:

- Be respectful and patient. People arrive with different skills and
  different machines; answer the question that was asked.
- Assume good faith. A report that looks wrong is usually a machine or a
  version you have not seen yet.
- Stay on the topic of the issue or pull request.
- No harassment, threats, slurs or personal attacks, and no spam.

The maintainer may edit or remove comments, close threads, or block
accounts that break these rules, without debate in the thread itself.
Decisions can be appealed once, privately, through GitHub.
