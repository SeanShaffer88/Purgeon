# Getting help

## Start with Purgeon Health

Open **Purgeon Health** from the command bar inside Purgeon. It checks
Purgeon's own files, data folder, settings and background tasks, and
names the fix for anything it finds. Many problems end there.

## Ask on GitHub

Bugs and requests go to the
[issue tracker](https://github.com/SeanShaffer88/Purgeon/issues). One
issue per problem works best. Please include:

- The Purgeon version (shown in the title bar and in Settings).
- Your Windows version (for example "Windows 11 24H2").
- What you clicked, in order, and the exact message Purgeon showed.
- What Purgeon Health reports, if the problem is with Purgeon itself.

## What support can and cannot do

Purgeon is a free program kept by one maintainer (see
[MAINTAINERS.md](MAINTAINERS.md)). Reports are read and answered as time
allows. Support cannot recover a program whose own uninstaller removed
files outside Purgeon's backups, and cannot undo a change that Purgeon
marked as not undoable before you confirmed it — everything else can
normally be restored from the Backups page.
