# Governance

Purgeon is a solo-maintainer project.

- **Decisions.** The maintainer (see [MAINTAINERS.md](MAINTAINERS.md))
  makes all product and technical decisions. Suggestions are welcome as
  issues; a good suggestion explains the problem it solves.
- **Versioning.** Releases use semantic versioning: fixes bump the
  patch number, new abilities bump the minor number, and breaking
  changes bump the major number.
- **Releases.** Fixes and features gather on the main branch and ship
  together in grouped releases rather than one release per fix. Every
  release is published by the maintainer from the Releases page, with
  file hashes listed.
- **Licence.** Purgeon is free and MIT-licensed. Optional donations are
  allowed; there are no paid tiers, no ads and no data sales, and that
  does not change by release.
- **Conduct.** Participation follows the
  [code of conduct](CODE_OF_CONDUCT.md).
