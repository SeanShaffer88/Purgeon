# Maintainers

Purgeon is maintained by the repository owner,
[@SeanShaffer88](https://github.com/SeanShaffer88).

The maintainer reviews issues and pull requests, decides what ships,
and publishes releases. There are no other maintainers at this time;
offers to help are best made by opening an issue first (see
[CONTRIBUTING.md](CONTRIBUTING.md) and [GOVERNANCE.md](GOVERNANCE.md)).
