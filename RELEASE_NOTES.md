# Purgeon Release Notes

## Binaries

This release ships **unsigned** binaries (no code-signing certificate was applied).
Windows SmartScreen may show a warning when you download or run the installer.
This is expected for unsigned software — verify the download source and checksum
before installing, or build from source if you prefer.

## Assets

- `Purgeon-Setup.exe` — universal NSIS installer for all supported architectures
- `Purgeon-Setup.msi` — universal MSI installer for all supported architectures
- `Purgeon-Portable.zip` — portable package containing builds for each architecture
