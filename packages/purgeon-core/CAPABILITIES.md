# Capability inventory

Dialog selection uses injected `sys.openDialog` and `sys.saveDialog`; Tauri implementations remain in the application adapter. The canonical dispatcher has no Tauri import. New runtime ownership and dispatcher declarations are private infrastructure alongside this closure.

One canonical implementation per file. All feature calls use the canonical dispatcher. Approval is required by default, including queries with possible cache/migration or host effects. Static language/profile/damage reads, reviewed security-software inventory/preparation/status, and explicit cancellation controls skip the outer approval; cancellation still follows existing handler policy.

## Feature operations

The 274 named operations below retain dispatcher readiness and approval guards. The `measure` subpath also exports synchronous `onMeasured(listener)`, a ready-state-guarded subscription returning unsubscribe. Each listener receives its own result snapshot from `measure`/`measureStore`; invalid listeners reject. Packed-consumer tests verify a 2,048-byte fake-host measurement, listener isolation and unsubscribe without Windows operations.
