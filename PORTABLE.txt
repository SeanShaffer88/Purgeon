Purgeon Portable

Extract the entire ZIP to a writable folder before running the executable.
Run Purgeon-Portable-x64.exe. Purgeon is 64-bit only: it needs 64-bit
Windows 10 or 11.
Settings and data live in the adjacent "Purgeon Data" folder. Keep the
executable's name: "Portable" enables portable storage automatically.

Settings, backups, snapshots and WebView2 data stay in that data folder. Carry
the whole folder with you, and back it up before replacing the executable.
An existing "SweepUninstall Data" folder remains supported for migration.

Microsoft Edge WebView2 is required. The portable package does not install
WebView2. The current application requests administrator rights.
The executable is unsigned.

Portable means no app installation is required. Uninstalling software, cleaning
files, changing settings or enabling scheduled tasks still changes the host PC.
Use Purgeon's preview and backup features before making changes.
